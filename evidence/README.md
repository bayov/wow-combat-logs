# Evidence

Screenshots that back up findings from the logs.

- `blood-fury-character-sheet.png`: the Orc shaman's character sheet before Blood Fury (top) and
  with it up (bottom), on the Classic beta, 2026-10-11. Attack power, spell power and healing go
  up 10%, and so does the main hand damage range (189.8-236.8 to 211.1-258.1, average 213.31 to
  234.64). The extra 38 attack power alone would add only 9 at 3.3 speed, so Blood Fury also
  adds 10% of the weapon's damage. The matching combat log is
  `classic_beta/WoWCombatLog-101126_202029.txt.xz`.
